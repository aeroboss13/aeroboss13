Всем привет! В разработке у меня и команды находится проект Пабит (https://pabit.ru). Это удобный, быстрый и функциональный проект для управления задачами в командах с возможностью видеозвонков, встроенным файлообменником и потрясающем дизайном (вернее, с выбором из 3-х доступных потрясающих дизайнов). Там же можно найти Pabion (https://pabit.ru/pabion) - полноценный SOC для компаний и команд безопасности. Внутри найдете AI Firewall, SIEM, DLP, EDR, XDR и много других фич. 1 подключаемый ПК - бесплатно для теста. Пользуйтесь!
